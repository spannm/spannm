#### Hi & thanks for visiting!

I'm a developer from Munich/Germany. My main open source projects:

- [UCanAccess](https://github.com/spannm/ucanaccess) [:speech_balloon:](https://github.com/spannm/ucanaccess/discussions "Discussions") and
  [Jackcess](https://github.com/spannm/jackcess) [:speech_balloon:](https://github.com/spannm/jackcess/discussions "Discussions"),
  pure Java libraries for reading and writing Microsoft Access databases
  (.mdb, .accdb). UCanAccess is a JDBC driver built on top of Jackcess.
  I contributed to the original UCanAccess project, and development
  continues here. [jackcess-encrypt](https://github.com/spannm/jackcess-encrypt)
  adds support for encrypted files.
- [iban-commons](https://github.com/SpeedBankingDe/iban-commons) [:speech_balloon:](https://github.com/SpeedBankingDe/iban-commons/discussions "Discussions"),
  an allocation-free IBAN and BIC toolkit for Java 8+.
- [figlet](https://github.com/spannm/figlet) [:speech_balloon:](https://github.com/spannm/figlet/discussions "Discussions"),
  a Java library and Maven plugin that renders text as ASCII art banners,
  without a native figlet binary.

I also help maintain [jFairy](https://github.com/SkillPanel/jfairy), a fake
data generator, and enjoy sending fixes upstream, e.g. to jdbi, Prowide
and the Apache Maven plugins.
